# Facebook Lead Ads Integration

This CRM is configured to receive real-time leads from Facebook Lead Forms via Webhooks.

## Prerequisites

1.  A **Facebook Developer Account** (developers.facebook.com).
2.  A **Facebook App** created as a "Business" app.
3.  A **Facebook Page** associated with your business.

## Step 1: Configure Environment Variables

Open your `backend/.env` file and add the following:

```env
FB_verify_TOKEN=my_secure_verification_string
FB_ACCESS_TOKEN=YOUR_LONG_LIVED_PAGE_ACCESS_TOKEN
```

*   `FB_Verify_TOKEN`: Any random string you create (e.g., "crm_webhook_verify_123"). You will need this in Step 3.
*   `FB_ACCESS_TOKEN`: A Page Access Token that has permissions to read leads.

## Step 2: Get Your Page Access Token

1.  Go to the [Graph API Explorer](https://developers.facebook.com/tools/explorer/).
2.  Select your App.
3.  Select "Get Page Access Token".
4.  Select your Facebook Page.
5.  Add the permission: `leads_retrieval` and `pages_show_list`.
6.  Generate the token and copy it to your `.env` file as `FB_ACCESS_TOKEN`.

## Step 3: Set Up Webhook

1.  Go to your App Dashboard -> **Webhooks**.
2.  Select "Page" from the dropdown.
3.  Click "Subscribe to this object".
4.  **Callback URL**: `https://wise-needles-repeat.loca.lt/api/webhooks/facebook`
    *   *Note: This URL was generated by your active localtunnel session. It is temporary and will change if you restart the tunnel.*
5.  **Verify Token**: Enter the `FB_Verify_TOKEN` you set in Step 1.
6.  Click "Verify and Save".

## Step 4: Subscribe to Fields

1.  In the Webhooks section, find `leadgen`.
2.  Click **"Subscribe"**.
3.  **IMPORTANT**: A popup will appear. Check the box next to your **Facebook Page** and click "Subscribe".

## Step 5: Test Integration

1.  Go to the [Lead Ads Testing Tool](https://developers.facebook.com/tools/lead-ads-testing/).
2.  Select your Page and Lead Form.
3.  Click "Create Lead".
4.  Check your CRM Dashboard -> "Leads". You should see the new lead appear instantly!

## Troubleshooting

*   **Webhook Verification Failed**: Ensure your server is running and the verify token matches exactly.
57. *   **Lead Not Saving**: Check the backend console logs. If `FB_ACCESS_TOKEN` is missing or invalid, it will save a placeholder lead instead of fetching real details.
58. *   **Error: "You have no page available"**:
59.     1.  Go to [Graph API Explorer](https://developers.facebook.com/tools/explorer/).
60.     2.  Select your App in the top right.
61.     3.  Click "Get Token" -> "Get Page Access Token".
62.     4.  A popup will appear. **Select your Page** and click Next.
63.     5.  Go back to the Debug Tool and refresh.
